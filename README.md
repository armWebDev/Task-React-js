## Features

- **Responsive Header:** Horizontal menu with sticky behavior. Hides on scroll down >200px and reappears on scroll up. Not shown on mobile or tablet screens.  
- **Search Posts:** Search by post title or text with live filtering.  
- **Post Popups:** Click on a post to see full details (title and text) in a popup. Close the popup by clicking outside or on the "Close" button.  
- **Mobile-Friendly Menu:** Hamburger menu slides in/out on mobile screens.
